## 2. 技術的に確認させていただきたい事項

### 2-1. コントラクトデプロイ

1. MCH Verse mainnet（chainId 29548）に **サードパーティが任意のコントラクトをデプロイできますか**。
2. 申請制・許可制の場合、必要な書類・審査基準・標準的なリードタイムをご教示ください。
3. テスト用の testnet（sandverse など）の利用可否と、本番との差分。

### 2-2. ガス（OAS）

4. MCH Corp 様によるガス補助の対象範囲は MCH 公式タイトルに限定されますか。それともサードパーティ製のタイトルも対象になり得ますか。
5. 補助対象になり得る場合、適用基準（売上分配、申請、月額上限等）。
6. 補助対象外の場合に取りうる選択肢:
   - 開発者が OAS を Sequencer / Validator に直接支払う方式
   - エンドユーザに OAS 残高を持たせる方式
   - 独自 Paymaster（ERC-4337）でガス代行する方式
   のうち、推奨ないし許容される運用形態。

### 2-3. ランダム性

7. MCH Verse 上で利用可能な **VRF（検証可能乱数）** ソースの提供有無（Chainlink VRF / Pyth Entropy / Supra / 独自実装、いずれか）。
8. 提供が無い場合に推奨される代替手段（`block.prevrandao` 利用 / commit-reveal / オフチェーン署名付き乱数等）。

### 2-4. アカウントアブストラクション

9. MCH Verse 上に **ERC-4337 標準の EntryPoint コントラクト** は公式にデプロイされていますか（アドレス）。
10. 公式 Paymaster の提供有無。
11. Smart Account を用いた session key 方式のゲーム実装を行う際に、MCH Corp 様としての推奨パターン・制約。

### 2-5. インデクサ / RPC / Sequencer

12. **mainnet 用 Subgraph エンドポイント**（GraphQL）の公式提供有無。
13. パブリック RPC のレート制限（IP 単位 req/s）と、WebSocket（`eth_subscribe`）対応の可否。
14. 1 秒あたりの実効 TPS と、ピーク時に他マイクリタイトルとどう帯域を共有するかの方針。
15. 「ゲームから秒間 N 件のトランザクションを送出する想定」の場合に Sequencer 側に与える影響について、想定すべきしきい値があればご教示ください。

### 2-6. 既存 NFT との連携

16. 以下の **MCH Verse 上のコントラクトアドレス** をご教示ください（公開情報からは確定できなかったもの）。
    - MyCryptoHeroes:Hero（MCHH 相当）
    - MyCryptoHeroes:Land
    - MyCryptoHeroes:Extension
    - MyCryptoHeroes:Achievement
    - Soulbound 系 NFT（SBH 等）
    - その他、ゲーム内資産として扱われる主要コントラクト
17. これらの NFT に対して `ownerOf` / `balanceOf` をゲーム内コントラクトから read する利用について、制約はありますか（Soulbound の場合、移転は不要で読み取りのみを想定）。
18. ゲーム内でこれらの NFT のアートワークを **画像として** クライアント側に表示する利用に関するライセンス上の取り扱い。

### 2-7. 経済設計

19. ゲーム内で `MCHC`（ERC-20: `0x9e5AAC1Ba1a2e6aEd6b32689DFcF62A509Ca96f3`）を賭け金や報酬として使用するゲームを稼働させる場合、規約上の制約（GambleFi 該当性、地域制限等）。
20. 独自のゲーム内 ERC-20（資源トークン等）を MCH Verse に追加発行することの可否・条件。

### 2-8. 商標 / IP

21. "MyCryptoHeroes" "マイクリ" を含むタイトル名・ロゴの **派生製品としての使用ガイドライン**。
22. ゲーム内画面に MCH キャラクター名や立ち絵を表示する場合のライセンス（公式アセットの提供有無、規程）。

### 2-9. 開発者窓口

23. 今後のテクニカル相談・コントラクト審査申請・障害連絡の **常設窓口**（Discord 開発者ロール / GitHub Discussions / メール）。
